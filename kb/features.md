# Product Features & Capabilities

## Platform Overview
Loomo is a **collaborative workspace platform** designed for mid-market and enterprise teams. It combines project management, document collaboration, internal communication, and workflow automation into a single platform. Loomo is available as a **web application** (all modern browsers) and native **desktop apps** for macOS and Windows.

## Core Features (All Plans)
All Loomo plans include:
- **Project Management**: Kanban boards, Gantt charts, task assignments, due dates, and dependencies
- **Document Collaboration**: Real-time co-editing, version history, comments, and @mentions
- **Team Messaging**: Channels, direct messages, threads, and file sharing
- **File Storage**: Centralized file storage with drag-and-drop upload, preview, and search
- **Search**: Full-text search across projects, documents, messages, and files
- **Mobile Access**: iOS and Android apps with full feature parity
- **Notifications**: Customizable email and in-app notifications for assignments, mentions, and deadlines

## Business Plan Features
In addition to all Pro features, Business plans include:
- **Custom Workflows**: Automated task routing, approval chains, and status triggers
- **Advanced Reporting**: Custom dashboards, export to CSV/PDF, and scheduled reports
- **Guest Access**: Invite external collaborators with limited, view-only or comment-only permissions
- **Priority Support**: Live chat support and 12-hour email response target

## Enterprise Plan Features
In addition to all Business features, Enterprise plans include:
- **SSO/SAML Integration**: Single Sign-On via SAML 2.0, OIDC, or Active Directory
- **API Access**: Full REST API for programmatic data access, automation, and integration
- **Audit Log**: Comprehensive activity log with user actions, timestamps, and IP addresses — exportable and searchable
- **Custom Data Retention**: Configurable retention periods and automated data lifecycle management
- **Dedicated CSM**: Assigned Customer Success Manager for strategic guidance and support
- **24/7 Phone Support**: Round-the-clock phone support for critical issues
- **Custom Integrations**: Dedicated integration engineering support for complex workflows
- **Data Residency Options**: Choice of US, EU, or APAC data hosting regions

## Integrations
Loomo integrates with the following third-party platforms:
- **Slack**: Two-way sync for messages and notifications
- **Google Workspace**: Import/export for Docs, Sheets, and Drive files
- **Microsoft 365**: Import/export for Word, Excel, and OneDrive files
- **Jira**: Two-way sync for issue tracking and project boards
- **Salesforce**: Contact and opportunity sync (Enterprise only)
- **Zapier**: 500+ app integrations via triggers and actions (Business and Enterprise)
- **Webhooks**: Custom HTTP webhooks for event-driven workflows (Business and Enterprise)

Integration configuration is available in **Settings → Integrations**. Enterprise customers can request custom integrations through their CSM.

## Data Export Options
All customers can export their data in the following formats:
- **CSV**: Tabular data including tasks, projects, and user lists
- **JSON**: Structured data for programmatic use
- **PDF**: Reports, documents, and dashboards

Exports are initiated in **Settings → Account → Export Data** and delivered as a ZIP file within **24 hours**. Enterprise customers with API access can use the **Export API** for automated, scheduled exports.

## Mobile Apps
Loomo's mobile apps for **iOS** (14.0+) and **Android** (11.0+) provide full feature parity with the web application, including:
- Project and task management
- Document viewing and commenting (editing on tablet devices)
- Team messaging and file sharing
- Push notifications

Mobile apps are available on the App Store and Google Play.

## Browser Compatibility
The Loomo web application supports the following browsers:
- **Chrome** 90+
- **Firefox** 90+
- **Safari** 15+
- **Edge** 90+

Older browser versions may experience degraded performance or missing features. Internet Explorer is **not supported**.
