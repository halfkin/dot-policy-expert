# Data Privacy & Security Policy

## Data Encryption Standards
Customer data is encrypted at rest using **AES-256**. Data in transit is encrypted using **TLS 1.2+**.

## Compliance Commitments
Loomo is **SOC2 Type II certified** and **GDPR compliant**. These standards apply to Loomo Hub’s handling of customer data.

## Breach Notification Timeline
In the event of a confirmed data breach, Loomo will notify affected customers within **72 hours**. Notification is provided to impacted customers once the breach is confirmed.

## Right to Be Forgotten Deletion SLA
Upon receiving a formal “Right to be Forgotten” request, Loomo will purge all identifiable user data within **30 days**. This timeline applies after the formal request is received.

## Account Deletion Data Scrubbing Timeline
Accounts marked for deletion enter a “soft-delete” state for **45 days**. Permanent data scrubbing occurs after the soft-delete period ends.

## Plan-Based Data Retention Periods
**Pro** accounts retain data for **1 year**. **Business** accounts retain data for **3 years**, and **Enterprise** accounts retain data **unlimited**.
